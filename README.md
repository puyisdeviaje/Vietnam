# Puyis en Vietnam

Blog del viaje a Vietnam (19 dic 2026 – 4 ene 2027), publicado con GitHub Pages.

- `site.yml`: datos generales (título, fechas, ruta).
- `dias/NN-lugar/`: una carpeta por día publicado (`entrada.yml`, `mapa.jpg`, `ruta.geojson`, `fotos/`).
- `tools/build.py`: genera `index.html` y las páginas de cada día.
- `borradores/`: entradas pendientes de aprobar; no se suben al repositorio.
